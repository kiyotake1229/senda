遊び方

表示された語をローマ字で打つだけ。正確さと速さでスコアとランクが決まります。

IMEはオフで

日本語入力をオフ（半角英数）にして打ちます。「し」は si でも shi でも、「ん」は n でも nn でも、どの打ち方でも通ります。表示は打ち方に合わせて変わります。

コンボと閃

ミスなく打ち続けるとコンボが伸び、音が高く、光が強くなります。10 / 25 / 50 / 100 / 200 で演出が変わります。ミスをすると 0 に戻ります。

スコアとランク

スコア = KPM × 正確率³ × コンボ補正。速くても雑だと伸びません。800 で最高位「神速」。結果の弱点キーから特訓へ進めます。
