# お題を3,722語に増量（閃打）

- 管理番号: #0002
- 種類: ENH（機能改善）
- 対象: お題データ（DAT）
- 作成日: 2026-09-18
- 関連: #0003（出題のランダム化。同じ依頼「語彙数を大幅に増やして出題をランダムにして」の対応）

## 概要

お題を 650 語から 3,722 語に増やし、デッキを 8 から 11 にした。新しいデッキは「カタカナ語」「生きもの・季節」「日本の地名」の3つ。読みはすべて複数の方法で確認した。今後お題を足すときに同じ確認ができるよう、検査ツール `tools/check_decks.py` を追加した。

## 対象ファイル

- `index.html` … お題データ `window.DECKS`（`<script>` の3つ目）を差し替え。ファイルは約 160KB → 約 348KB
- `tools/check_decks.py` … 新規。お題の検査ツール
- `tools/reading.swift` … 新規。macOS の日本語解析で読みを出す補助（`check_decks.py --mac` が使う）

### 品質の確認方法

読みの誤りは「そのお題が誰にも正しく打てない」不具合になるため、次の順で確認した。

1. **生成**: テーマごとに 32 バッチで作成（例: 日常のことば＝家・食べ物・体・町・動詞と形容詞）
2. **校正（全件）**: 別の担当が全件の読みとテーマ適合を確認。テーマ外の 35 語を外し（すし屋デッキに混ざった焼き鳥・居酒屋の語など）、長文の読み1件を修正
3. **二重確認（ことわざ・地名）**: さらに別の担当が「疑わしければ挙げる」方針で確認。指摘は0件。作業者も全 380 件を目視で確認
4. **自動検査（全件）**: 文字種・表示とよみの送り仮名の整合・長さ・重複・ローマ字エンジンで最後まで打てるか。エラー0件
5. **macOS の日本語解析との突き合わせ（日本語の全 3,212 件）**: 読みが食い違った 206 件を作業者が全件目視。ほとんどは macOS 側の連濁の誤り（富士山→ふじやま 等）で、本物の誤りが2件見つかり修正した
   - 「年下の上司にも少し慣れてきた。」の「年下」が「とした」になっていた → 正しくは「としした」
   - 「…聞こえるのは川の音と鳥の声だけだった。」の「音と鳥」が「おととり」になっていた → 正しくは「おとととり」
6. **英語（510 件）**: macOS のスペルチェッカーで全件確認。指摘0件

2 と 3 では見つからず、5 で見つかった誤りは「同じ仮名が続く箇所で1文字抜ける」種類だった。今後も 5 を必ず行う。

### 検査ツール

```bash
python3 tools/check_decks.py        # 形式・送り仮名の整合・重複・打てるか（node が必要）
python3 tools/check_decks.py --mac  # さらに macOS の読みと突き合わせ（差分は目視確認の候補）
```

`--mac` の差分 204 件は、今回すべて目視で確認済み（連濁などで macOS が誤るもの）。お題を足したときは、差分のうち新しく増えた行だけを見ればよい。
