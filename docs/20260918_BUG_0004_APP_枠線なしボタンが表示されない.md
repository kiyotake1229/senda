# 枠線なしボタンが表示されない（閃打）

- 管理番号: #0004
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-18
- 関連: なし

## 概要

枠線なしの見た目のボタン（クラス `btn ghost`）が透明になり、画面に出ていなかった。ゴーストレース（自己ベストとの競走表示）の枠にも同じ `ghost` というクラス名を使っていて、その「最初は透明」の指定がボタンにも当たっていたのが原因。レース側のクラス名を `ghostrace` に変えて直した。

## 対象ファイル

- `index.html` … CSS の `.ghost` 系の指定（ゴーストレース用）を `.ghostrace` に改名。HTML の `<div class="ghost" id="ghost">` を `class="ghostrace"` に変更。JavaScript は `id="ghost"` で参照しているので変更なし

## 変更内容

表示されていなかったボタン:

| 画面 | ボタン |
|---|---|
| 結果 | ホーム（Esc） |
| 一時停止 | やめてホームへ |
| 設定 | 記録をすべて消す |

- キーボード操作（Esc）では動いていたため、デスクトップでは気づきにくかった。スマホやマウス操作では、結果画面からホームに戻る手段がなかった
- 修正後、3つとも表示されることと、ゴーストレースの表示（自己ベストがあるときだけ出る）が変わらないことを確認した
