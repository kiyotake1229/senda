# 打ち始めの速い入力がミスになる（閃打）

- 管理番号: #0014
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: #0015（実機での動作確認。この不具合はその確認中に見つかった）

## 概要

ホーム画面の語を打ち始めてプレイに入るとき、最初の1文字だけを「少し後で処理する」作り（`setTimeout(…, 0)`）にしていた。そのため、2文字目以降がその前に届くと先に処理され、順番が逆になってミス扱いになった。画面が裏にあってタイマーが遅れるときや、非常に速く打ったときに起きる。最初の1文字をその場で処理するように直した。

## 対象ファイル

- `index.html` … 関数 `startRun` の最後の `opts.firstChar` の処理

## 変更内容

- 変更前: `if(opts.firstChar)setTimeout(()=>handleChar(opts.firstChar),0);`
- 変更後: `if(opts.firstChar)handleChar(opts.firstChar);`
- 見つけた経緯: 実際の Chrome（Claude in Chrome）でホームの「決算（kessann）」を打つと、プレイには入るが最初の語が進まず、正確率が 14.3%（7打中1打だけ正解）になった。Chrome はウィンドウが裏にあるとタイマーを遅らせるため、後の6文字が先に処理されていた
