# スマホで端末のキーボードが勝手に出る（閃打）

- 管理番号: #0019
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）

## 概要

スマホで画面キーボード（フリック・画面ローマ字）を使う設定なのに、ときどきスマホ本体のキーボードが出てきた。以前の入力方式で使っていた見えない入力欄（`#hid`）に、入力先が移る処理が残っていたため。端末のキーボードを使う設定（外付け）のときだけ働くように直した。利用者の報告で見つかった。

## 原因

画面キーボードを入れたとき（#0016）に、画面の切り替え時の処理は直したが、次の3か所が残っていた。

| 操作 | 残っていた処理 |
|---|---|
| 「遊び方」を閉じる（初めて開いたときは毎回） | `closeHelp` で入力欄に入力先を移していた |
| ホームの開始カード（「はじめる」の周り）を押す | 開始カードのクリックで入力欄に入力先を移していた |
| 一時停止から「再開する」を押す | 再開ボタンで入力欄に入力先を移していた |

## 対象ファイル

- `index.html` … 関数 `focusHid`・`syncHid`・`useSysKb` を追加。入力欄に入力先を移す処理をすべて `focusHid` 経由にした

## 変更内容

- 入力欄に入力先を移す処理は、端末のキーボードを使う設定（外付け）のときだけ動く（`focusHid`）
- 画面キーボードの設定のときは、入力欄そのものを「読み取り専用・キーボードを出さない（`inputmode="none"`）・キー操作で移れない」状態にする（`syncHid`）。入力方式を切り替えたときにも合わせる
- 万一入力先が移っても、すぐに外す
- 外付けの設定と、パソコンでの動きは変わらない
