# 語の長さを選べるように（閃打）

- 管理番号: #0011
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: #0003（山札方式）

## 概要

ホームのお題の下に「長さ: ぜんぶ / みじかめ / ながめ」を追加した。ミックスで2文字の単語と長い慣用句や文が交互に出てリズムが崩れる問題への対応。English デッキでは「みじかめ」が英単語、「ながめ」が英文になる。

## 対象ファイル

- `index.html` … ホームの `#lens`、CSS `.lens`・`.len`、関数 `inLen`・`pool`・`lenOk`・`effLen`・`bagKey`・`bagItems`・`lenLabel`、`bestKey`、`startRun`・`showResult`・`retry`、記録画面の表

## 変更内容

- 境目: 日本語はよみの字数 6 字以下が「みじかめ」、7 字以上が「ながめ」。英語は 12 字以下が「みじかめ」、13 字以上が「ながめ」
- 選んだ長さの語が 30 語に満たないデッキでは、その長さを押せなくする（例: 短文・長文デッキの「みじかめ」）。そのときは「ぜんぶ」で出題する
- 山札（#0003）は「デッキ×長さ」ごとに持つ（例: `mix|s`）。長さを変えても、それぞれ一巡するまで同じ語は出ない
- 自己ベストとゴーストも長さごとに分けて記録する（キーの例: `sprint:mix|s`）。短い語だけの記録と、ぜんぶの記録を混ぜないため
- プレイ画面・結果画面・記録画面のお題名に「・みじかめ」「・ながめ」を付ける
- 長さの選択は `localStorage` の `senda.v1` の `len` に保存する（既定は `all`）
- デイリー挑戦は長さを選べない（誰でも同じ出題にするため）
