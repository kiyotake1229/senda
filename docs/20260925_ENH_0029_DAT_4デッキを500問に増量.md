# カタカナ語・生きもの・すし屋・地名の4デッキを500問に増量（閃打）

- 管理番号: #0029
- 種類: ENH（機能改善）
- 対象: お題データ（DAT）
- 作成日: 2026-09-25
- 関連: #0002（お題を3,722語に増量）、#0003（出題のランダム化とミックス追加）

## 概要

問題数の少なかった4つのデッキ（200〜268問）を、それぞれ500問に増やした。お題の合計は 3,722 から 4,780 になり、ミックスは 2,952 から 4,010 問になった。1つのデッキだけを遊ぶ人でも、同じ問題がすぐ出てこないようにするため。利用者から「問題量は多い？」と聞かれ、少ないデッキは10回前後で一巡すると答えたのがきっかけ。

## 対象ファイル

- `index.html` … `window.DECKS` の4デッキに1,058問を追加。リンクの説明文（`og:description`）の語数
- `ogp.png`・`tools/ogp.html` … プレビュー画像の語数を「4,780 語」に
- `tools/check_decks.py` … 「ヶ」を含む表示（茅ヶ崎市・八ヶ岳 など）を正しく検査できるように修正
- `README.md` … 語数とテストの件数

- 語は区分ごとに「よく知られている順」に候補を並べ、区分ごとの枠の中で上から選んだ（区分の偏りを防ぐため）
- 他のデッキにすでにある語（ハンバーグ・虹・包丁 など56語）は足していない。表示が同じ語はデッキをまたいでも1つだけ
- 県庁所在地は全47のうち未収録だった29市をすべて入れ、47都道府県の県庁所在地がそろった
- 読みの紛らわしい語（日向＝ひなた／ひゅうが など）は外した

### 検査

- `python3 tools/check_decks.py`: 形式エラー0（よみの文字・表示とよみの整合・長さ・重複・表示どおりに最後まで打てるか）
- `python3 tools/check_decks.py --mac`: 追加分のうち macOS の読みと違うものが98件あり、すべて目で確認した。どれも macOS 側の読み違いだった（連濁の「〜がわ」「〜ずし」を濁らない、「東大寺」を「ひがしだいじ」、「清水寺」を「しみずてら」と読む など）。差分の合計は 204 → 302 件
- `node tools/test_romaji.js`: 34,245件合格（お題4,780件をすべて含む）
- `node tools/test_kana.js`: 9,097件合格（フリック4,270問、画面ローマ字4,780問）

### 検査ツールの修正

`tools/check_decks.py` は「ヶ」をカタカナとして「ゖ」に変換していたため、「茅ヶ崎市（ちがさきし）」のような表示を「表示とよみが食い違う」と判定していた。「ヶ」は漢字と同じ扱い（読みは「が」「か」など）にした。これで「茅ヶ崎市・槍ヶ岳・八ヶ岳・霞ヶ浦・城ヶ島・酸ヶ湯」を候補に入れられるようになった。

### 利用者の端末への影響

山札（出題順）はデッキの語数が変わると自動で作り直されるので、次に遊んだときから新しい語が混ざる。自己ベストや記録はそのまま。
