# 記録画面と実績のフリック対応（閃打）

- 管理番号: #0026
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード。入力方式ごとの記録とランク）

## 概要

記録画面（スコアの推移・キーの弱点）と実績の一部は、パソコンのローマ字入力を前提にしていた。フリックは1文字あたりの操作が少ないぶん数字が小さく出るため、フリックの人には意味の合わない表示・届かない実績になっていた。入力方式ごとに見るようにした。

## 対象ファイル

- `index.html` … `renderStats`・関数 `kanaWeakCard` を追加、結果の集計（かなごとの記録 `S.kstats`）、実績の条件

## 変更内容

### 記録画面

- 「スコアの推移」は、いま選んでいる入力方式の走りだけを表示する。ランクの目安線もその入力方式の基準で引く。スマホでは見出しに入力方式を出す（例「スコアの推移（フリック）」）
- フリックのときは、キーボードの図（ミス率の色分け）の代わりに「苦手なかな」を出す。かなごとに、打った回数・ミスの回数・前の文字から打つまでの時間を記録し、ミスが多い・時間がかかるかなを最大10個並べる。8回以上打ったかなが6つ以上たまるまでは案内を出す
- フリックの走りは、これまでどおりパソコンのキーの記録には混ぜない

### 実績

| 実績 | 変更前 | 変更後 |
|---|---|---|
| 達人 | スコア500以上 | その入力方式の基準でランク S 以上 |
| 閃 | スコア800以上 | その入力方式の基準で最高位（神速） |
| 疾風の指 | KPM 300以上 | KPM 300以上（フリックは160以上） |
| 神速の指 | KPM 500以上 | KPM 500以上（フリックは260以上） |

パソコンの条件は変わらない。フリックの基準は暫定値で、実際に遊んだ記録が集まったら見直す。

確認した内容（アプリ内ブラウザのスマホ表示で、画面キーボードのフリックを自動で操作して60秒のスプリントを3回）: 1回目は KPM 187・スコア178で、フリックの基準でランク B（中級）と判定され、「疾風の指」が解除され「神速の指」は解除されないこと。記録画面で、推移がフリックの走り3回だけで描かれ、ランクの目安線がフリックの基準（B・C・D）で引かれること。「苦手なかな」に、わざとミスを混ぜた「か・し・た」（ミス率45〜50%）と、わざと遅く打った「ん・と」（595〜775ms）が並ぶこと。
