# 文字の読みやすさとスマホ向けの案内（閃打）

- 管理番号: #0008
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: #0005、#0006

## 概要

薄い文字（ラベル・ヒント・まだ打っていない文字）が背景に対して暗すぎて読みにくかったので、色を明るくした。スマホではキーボード操作の案内（Enter・Tab・Esc や「IME をオフに」）が意味をなさないため、スマホ向けの案内に切り替えるようにした。あわせて、長い文がスマホ幅でカードからはみ出す崩れを直した。

## 対象ファイル

- `index.html` … CSS の色の定義（`--tx3`、新しい `--tx4`）、`.s-ro`・`.s-kana`・`.start .w-ro` など、`.touch` 用の指定、ホームの案内 `.hint-touch`、遊び方の文 `#help-ime-t`・`#help-ime-p`

## 変更内容

### 文字の色（コントラスト比 = 文字と背景の明るさの差。読みやすさの目安は小さい文字で 4.5:1 以上、大きい文字で 3:1 以上）

| 用途 | 変更前 | 変更後 |
|---|---|---|
| 薄い文字 `--tx3`（ラベル・ヒント・読みがなの未入力部分など 25か所） | #586279（2.8〜3.2:1） | #808BA5（カード上 5.0:1、背景上 5.7:1） |
| まだ打っていないローマ字（34px・大きい文字） | #586279 | 新しい `--tx4` #66718B（3.5〜3.9:1）。打った部分との差を残すため少し暗めにした |
| スマホ幅のローマ字（22px） | #586279 | `--tx3`（4.5:1 以上。大きい文字の扱いにならないため） |
| 読みがなの打ち終えた部分 | `--tx2`（灰色） | アクセント色の 62%（未入力の灰色と見分けやすくした） |

### スマホ向けの案内（タッチ端末のとき、ページの根に `touch` クラスを付けて切り替える）

- ホームの「Enter / Space でも開始・Tab お題を変える・Esc 戻る」を隠し、「語をタップするとキーボードが出ます」を出す
- ボタンの中のキー表示（Enter・Esc）を隠す
- 遊び方の1枚目を「IMEはオフで」から「英語キーボードで（英語（ABC）キーボードに切り替えて打つ）」に変える
- プレイ開始前の案内に「画面をタップするとキーボードが出ます」を足す

### スマホ幅の崩れ

- ホームの開始カードで、長い文のローマ字・読みがなが折り返されずに横へはみ出し、ページ全体が横に広がっていた。折り返すようにし、グリッドの列が中身に押し広げられないようにした（`minmax(0, …)`・`min-width:0`）
