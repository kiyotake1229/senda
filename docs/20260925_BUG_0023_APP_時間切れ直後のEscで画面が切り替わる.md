# 時間切れ直後の Esc でホームに戻り、そのあと結果画面が出る（閃打）

- 管理番号: #0023
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: なし

## 概要

時間切れ（または練習モードの「終了して結果を見る」）から結果画面に移るまでの約0.5秒のあいだに Esc を押すと、いったんホームに戻り、その直後に結果画面が勝手に出ていた。終わりかけの走りを「まだ始まっていない走り」と同じに扱って、ホームに戻る処理をしていたため。

## 対象ファイル

- `index.html` … キー操作の処理（Esc）

## 変更内容

- 走りが終わってから結果画面が出るまでのあいだは、Esc を受け付けない
- 一時停止ボタンなど、ほかの操作はもともとこのあいだ受け付けていない

## 確認URL

| 環境 | URL |
|------|-----|
| ローカル | http://localhost:8791/ （パソコンでスマホの動きを見るときは `?touch=1` を付ける） |
| 開発確認（Artifact） | https://claude.ai/artifact/FuXyid2Rqz9HzPQAVQffZ5 |
| 本番（GitHub Pages） | https://kiyotake1229.github.io/senda/ |

確認した内容（アプリ内ブラウザ）: 練習モードで「終了して結果を見る」を押した0.08秒後に Esc を送り、画面が「プレイ → 結果」とだけ移り、ホームを経由しないこと。
