## 概要

## 仕様

### 画面と機能

画面は6つ。HTML では `<section class="scr" id="scr-...">` で、関数 `show(id)` が切り替える。上に重ねる画面（オーバーレイ）は `#ovl-pause`（一時停止）・`#ovl-cd`（カウントダウン）・`#ovl-help`（遊び方）・`#ovl-share`（結果カード）の4つ。

**ホーム（`#scr-home`、関数 `renderHome`）**

- 表示中の語（`#hw-main`）を打ち始めると、そのままプレイが始まる。1文字目が合っているときだけ始まる
- Enter / Space / 「はじめる」ボタン（`#b-start`）でも開始。Tab で語を変える
- モード5種（`#modes`）とお題8種（`#decks`）を選ぶ。デイリー挑戦を選ぶとお題は選べない
- 右側: 選んだモード×お題の自己ベスト（`#best`）、デイリー挑戦の状況と42日分の暦（`#daily`・`#cal`）、ひとこと（定数 `TIPS` から日替わり）
- 上部: 全自己ベストの最高スコアのランク（`#lvpill`）、連続プレイ日数（`#streak`）、記録・実績・設定・遊び方のボタン
- 日本語入力（IME）がオンだと警告（`#ime`）を出す
- 初回は遊び方（`#ovl-help`）を自動で開く。閉じると `S.help` が true になり、以後は出ない

**プレイ（`#scr-play`）**

- 上部: モード名・お題名、残り時間の円（`#p-timer`）、KPM・正確率・スコア（食べ放題は金額）
- 中央: 表示文字（`#s-text`）、かな（`#s-kana`）、ローマ字（`#s-ro`）、次の語（`#s-next`）。打った所まで色が変わる。English デッキはかなを出さない
- 最初の1打で計測が始まる。間違ったキーは状態を変えない（正しいキーを打てば進む）
- 画面キーボード（`#kbd`）が次に押すキーを光らせる。指ごとの色線つき。Tab で表示を切り替え。タッチ端末と幅600px以下では出さない
- コンボ演出: 5以上で数字を表示。10 / 50 / 100 / 200 で色が変わる。25以上でハイハット音と背景の発光。節目（定数 `MILESTONES` = 10, 25, 50, 100, 150, 200, 300, 500）で輪の演出・効果音・振動
- ミス時: 画面が揺れ、赤いふちが出て、低い音が鳴り、コンボが0に戻る
- ゴースト（`#ghost`）: 同じモード×お題の自己ベストの「1秒ごとの累計正打数」をレールに出し、差を打数で示す
- Esc で一時停止（`#ovl-pause`）。打ち始める前ならホームへ戻る。再開時は 3・2・1 のカウントダウン（`#ovl-cd`）。タブを隠すと自動で一時停止
- タッチ端末は隠し入力欄（`#hid`）でソフトキーボードの文字を受け取る。入力欄から外れると「画面をタップして再開」（`#tap`）を出す
- OS の「視差効果を減らす」設定（`prefers-reduced-motion`）がオンなら、揺れ・パーティクルなどを止める

**モード（定数 `MODES`）**

| モード | キー | 時間 | 自己ベスト | ゴースト | 仕様の要点 |
|------|------|------|------|------|------|
| スプリント60 | `sprint` | 60秒 | スコアで記録 | あり | 基本のモード |
| デイリー挑戦 | `daily` | 60秒 | スコアで記録（キーは `daily:mix`） | あり | 日付を種にした乱数（`mulberry32`）で出題順が決まる（`dailyItems`）。出題元は `MIX_DECKS` の5デッキ。その日最初の有効プレイだけ「本番」として `S.daily` に保存。以後は「練習」 |
| 食べ放題 | `buffet` | 60秒＋延長 | 金額で記録 | なし | 語を打ち切ると金額を加算（`priceOf`: ローマ字4字以下100円 / 7字以下200円 / 10字以下300円 / 14字以下500円 / それ以上800円）。ノーミスで打ち切ると「0.4＋ローマ字の字数×0.09」秒延長。ミス1回で1秒減る。経過150秒で必ず終わる |
| 弱点特訓 | `drill` | 60秒 | スコアで記録 | あり | 弱点キーを多く含む語を前に並べる（`weightForWeak`）。弱点が判定できないと始まらない。設定「特訓のヒント減衰」がオンなら、同じキーを3回続けて正しく打つとキーボードの光が消える（1.5秒止まると再び光る） |
| 練習 | `free` | 無制限 | 記録しない | なし | 経過時間を表示。Esc の一時停止画面で「終了して結果を見る」（`#b-finish`。正打1以上で表示）を押すと結果へ |

弱点キーの判定（関数 `weakKeys`）: 累計10打以上のキーが6種類以上あるときだけ判定する。キーごとに「3×ミス率＋max(0, 反応時間÷全キーの中央値−1)」を出し、0.15を超えるキーを高い順に並べる。

**結果（`#scr-result`、関数 `showResult`）**

スコア式（関数 `scoreOf`）:

```
KPM    = 正打数 ÷ 経過分
正確率 = 正打数 ÷ (正打数 + ミス数)        ※ 0〜1 の値
スコア = 四捨五入( KPM × 正確率³ × (1 + min(最大コンボ, 300) ÷ 1500) )
```

ランク表（定数 `RANKS`）:

| ランク | 漢字 | スコア |
|---|---|---|
| SSS | 神速 | 800〜 |
| SS | 疾風 | 650〜 |
| S | 達人 | 500〜 |
| A | 上級 | 380〜 |
| B | 中級 | 280〜 |
| C | 初級 | 190〜 |
| D | 見習い | 100〜 |
| E | 入門 | 0〜 |

- 正打10未満のプレイは記録しない。ランクに「（参考）」がつき、「10打以上で記録されます」と出る
- ランクの漢字が左から現れる。SS は「疾」、SSS は「閃」の朱印が押される
- 自己ベストを更新すると「NEW RECORD」。自己ベストは練習以外のモードで、モード×お題ごとに1件（食べ放題は金額、ほかはスコアで比べる）
- 「次のランク『○○』まで あと N」。ミスがあったときは「ミス0なら +N」も出す
- 数値の枠: KPM・正確率・最大コンボ・語数・ミス・時間。食べ放題は合計金額と延長秒数も出す
- この回でミスが多かったキー上位3つと「このキーを特訓」ボタン（`#b-drill-now`）
- ボタン: もう一度（`#b-retry`、Enter）、結果カードを共有（`#b-share`、関数 `shareCard`）、テキストをコピー（`#b-copy`、関数 `resultText`）、ホーム（`#b-home`、Esc）
- 結果カードは canvas で作る 1200×630 の PNG。画像を長押し・右クリックで保存する。Web Share API でファイル共有できる端末だけ「共有する」（`#b-share-native`）を出す
- 実績の判定（関数 `checkAch`）はここで行う。達成すると上部に通知（`#achpop`）

**記録（`#scr-stats`、関数 `renderStats`）**

- 累計: 総打鍵とミス、プレイ回数と分数、最高 KPM と語数、最大コンボと最長連続日数
- スコアの推移: `MODES` で `ranked:true` のモード（スプリント・デイリー・食べ放題）の直近30回。3回未満なら出さない
- キーの弱点: キーボード図のミス率ヒートマップ（`KBD.heatSvg`。5打以上のキーを、ミス率0〜25%で色分け）と弱点キー（`weakKeys(6)`）。「この弱点を特訓する」ボタン（`#b-drill-stats`）
- 自己ベストの一覧、最近の12回

**実績（`#scr-ach`、関数 `renderAch`）**

16個（定数 `ACH`）。達成日を `S.ach` に保存する。

初閃（初めて記録）/ 五十連・百連・二百連（コンボ50・100・200）/ 無傷（150打以上でミス0）/ 疾風の指・神速の指（KPM 300・500）/ 達人（ランクS以上）/ 閃（神速）/ 七日皆勤（7日連続）/ 一万打・十万打（累計打鍵）/ 全席制覇（8デッキすべて）/ 日課十回（デイリー本番10回）/ 大食い（食べ放題で5,000円）/ 克己（弱点特訓5回）

**設定（`#scr-set`、関数 `renderSet`）**

- 音と手応え: 効果音の音量（`sfx`）、コンボのリズム音（`hat`）、触覚フィードバック（`haptic`）、ミス時の画面シェイク（`shake`）、パーティクル（`fx`）

- データ: 書き出し・読み込み・全消去（「データの保存」を参照）

### データの保存

- 保存先は `localStorage` のキー **`senda.v1`**（定数 `DB`）1つだけ。全データを JSON 文字列で丸ごと保存する（関数 `save`）
- 起動時に読み、初期値（関数 `DEF`）に上書きして合成する。設定 `set` は項目ごとに合成する
- 保存するのは正打10以上のプレイだけ

中身（変数 `S`）:

| 項目 | 内容 |
|------|------|
| `v` | 形式の版（1）。移行処理には使っていない |
| `best` | 自己ベスト。キーは `モード:お題`（例 `sprint:basic`。デイリーは `daily:mix`）。値は1回分の記録＋`ghost`（1秒ごとの累計正打数の配列。最大61件。ゴーストのあるモードだけ） |
| `hist` | 履歴。新しい順に最大120件 |
| `daily` | デイリー本番の記録。キーは日付 `YYYYMMDD` |
| `streak` | 連続日数 `{cur, best, last}`。`last` は最後に記録した日 |
| `keys` | キー別の累計 `{n: 打数, m: ミス数, lat: 反応時間ms}`。英小文字・数字・`- ; , . / '` だけ数える（正規表現 `KEYRE`）。押したキーではなく「その位置で打つべき文字」で数える |
| `ach` | 実績ID → 達成日 `YYYYMMDD` |
| `total` | 累計 `{runs, keys, miss, sec, words, money}` |
| `decks` | 一度でも走ったお題（全席制覇の判定用） |
| `help` | 遊び方を閉じたことがあるか |
| `mode` / `deck` | 最後に選んだモードとお題 |
| `set` | 設定 `{sfx, hat, shake, fx, kbd, fingers, accent, romaji, size, haptic, hints}` |

1回分の記録（`showResult` 内の `rec`）: `mode`, `deck`, `score`, `kpm`, `acc`（%、小数1桁）, `combo`, `words`, `correct`, `miss`, `sec`, `money`, `date`（`YYYYMMDD`）, `soft`（タッチ端末か）, `official`（デイリー本番か）

書き出し・読み込み（設定画面の「データ」）:

- 書き出し: テキスト欄（`#ta-data`）に `JSON.stringify(S)` をそのまま表示する。「コピー」（`#b-exp`）でクリップボードへ。形式は `senda.v1` の中身と同じ JSON
- 読み込み: テキスト欄に貼り「貼り付けた内容を読み込む」（`#b-imp`）。JSON として読めて `best` があれば、今のデータに上書きする（`Object.assign`）。それ以上の検査はしない
- 全消去: 「記録をすべて消す」（`#b-reset`）。確認のあと `senda.v1` を消して再読み込み
- iOS アプリ内（定数 `NATIVE` が true）では `window.Capacitor.Plugins.Preferences` にも同じ内容を書く。読み込みは `localStorage` からだけ

### 通信と外部リソース

- アプリがデータを外部へ送る処理は無い。`fetch`・`XMLHttpRequest`・`sendBeacon`・`WebSocket` は使っていない
- 外部から読むのは Google Fonts だけ。`<head>` の `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?...">` で、Shippori Mincho B1・Zen Kaku Gothic New・JetBrains Mono を読む。フォント本体は `fonts.gstatic.com` から来る
- フォントが読めなくても、CSS 変数 `--disp` / `--ui` / `--mono` に並べた端末のフォントで表示される
- CDN のスクリプトは使っていない
- 音は WebAudio で合成する（音声ファイルなし）。アイコンは HTML 内の SVG（`<symbol id="i-...">`）
- `sw.js` は、同じサイトのファイルと Google Fonts の応答をキャッシュする
- 結果カード画像に `kiyotake1229.github.io/senda`、コピー用テキストに `#閃打` の文字が入る（文字だけで通信ではない）

### 技術構成とコードの地図

素の HTML・CSS・JavaScript だけで作られている。ビルド作業もライブラリも無い。`index.html` の中身は上から次の順。

1. `<style>` … 全 CSS。色は `:root` の CSS 変数。アクセント色は `:root[data-accent=...]`、文字サイズは `:root[data-size=...]` で切り替える
2. SVG アイコン定義（`<symbol id="i-...">`）、各画面の HTML（`#scr-home` など）、オーバーレイ（`#ovl-...`）、隠し入力欄 `#hid`
3. `<script>` その1 … ローマ字入力エンジン（ROM）。コメント「ローマ字入力エンジン（全表記対応）」で探す
4. `<script>` その2 … お題データ（DAT）。`window.DECKS=` で始まる1行（約38KB）
5. `<script>` その3 … 本体の前半。コメント「閃打 SENDA — アプリ本体」で探す。最後に部品を `window.__SENDA` にまとめる
6. `<script>` その4 … 本体の後半。`const X=window.__SENDA` で前半の部品を受け取る。末尾が起動処理（コメント「起動」）

  - キャッシュ名は **`senda-v1`**（定数 `CACHE`）
  - インストール時に `./`・`./index.html`・`./manifest.json`・`./icon.svg`・`./icon-192.png` を保存（定数 `ASSETS`）

  - 有効化時に、名前の違う古いキャッシュを消す

### 既知の制限・注意点

**README と実装の食い違い（実装を正とした）**

- 練習モードの終わり方: README は「Esc で終了して結果を見る」。実装では Esc で一時停止画面を開き、「終了して結果を見る」ボタンを押す。一時停止画面で Esc を押すと「再開」になる。画面内の文言（`MODES` の練習モードの説明「時間無制限。Escで終了」、プレイ画面の `#startnote`）も Esc で終了できるように書いている
- 連続日数: README はデイリー挑戦の説明に書いている。実装はモードを問わず、正打10以上のプレイがあった日を数える（`showResult` 内の `S.streak` の更新）
- ゴーストと自己ベスト: README ではスプリント60の説明にだけある。実装ではゴーストはスプリント・デイリー・弱点特訓で出る。自己ベストは練習以外の4モードで記録する
- 「ミス0なら +N」: README は「常に表示」。実装ではミスがあったときだけ出す。正打10未満では「10打以上で記録されます」に置き換わる
- デイリーの暦: README は「記録」の項に挙げている。実装ではホーム画面のデイリー挑戦カード（`#cal`）にあり、記録画面には無い

**その他**

- 修正が利用者に届かないおそれ: `sw.js` はキャッシュ優先で、キャッシュ名 `senda-v1` が同じ限り保存済みの `index.html` を返し続ける。4cbfe56 の修正でも `sw.js` は変えていない。このため、それより前に本番を開いた端末では修正前の版が出続ける可能性がある（コードからの判断。実機では未確認）。`index.html` を直すときは `CACHE` の名前も上げる必要がある
