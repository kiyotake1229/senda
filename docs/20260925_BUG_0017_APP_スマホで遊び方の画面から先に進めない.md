# スマホで遊び方の画面から先に進めない（閃打）

- 管理番号: #0017
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）

## 概要

スマホで初めて開くと出る「遊び方」の画面が、画面より縦に長く、しかもスクロールできなかった。上下がはみ出して、閉じるための「はじめる」ボタンが画面の下端にかかるか、画面の低い端末では完全に画面の外に出た。そのため画面が固定されたように見え、先に進めなかった。利用者の報告（「スマホで開いたら画面が固定されてる」）で見つかった。

## 原因

- 重ねて出す画面（遊び方・一時停止・結果カードなど）は、画面の中央に置くだけの作りで、はみ出したときにスクロールできなかった
- ページ全体はゲームのためにスクロールを止めている（`html,body{overflow:hidden}`）ので、はみ出した部分に届く方法がなかった
- スマホ幅では遊び方の3枚のカードが縦に並び、枠の高さが 903px になっていた（高さ 812px の画面で上に 34px、下に 58px はみ出し）

## 対象ファイル

- `index.html` … CSS `.ovl`・`.ovl .box`・`#ovl-help`（`.help-body`・`.help-foot`）、遊び方の HTML、スマホ幅のカードの詰め方、背景を押して閉じる処理

## 変更内容

- 重ねて出す画面は、画面に収まらないときスクロールできるようにした。上下の端が切れないよう、中央寄せの方法を変えた（`margin:auto`）
- 遊び方は「本文」と「はじめる」ボタンに分け、本文だけが枠の中でスクロールする。ボタンは常に見える
- スマホ幅では遊び方のカードの余白と文字を少し詰めた
- 遊び方と結果カードは、周りの暗い部分を押しても閉じられるようにした
- 遊び方の冒頭文を「表示された語を打つだけ」に、スコアの説明を「最高位は『神速』」に変えた（フリック入力では基準の数値が違うため）
