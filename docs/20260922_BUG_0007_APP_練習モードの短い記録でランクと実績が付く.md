# 練習モードの短い記録でランクと実績が付く（閃打）

- 管理番号: #0007
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: なし

## 概要

練習モードは時間制限がなく、数秒だけ速く打って終えても KPM（1分あたりの打数）が非常に高く計算される。そのため、最高位「神速」のランク表示、結果カード、実績「疾風の指」「神速の指」、記録画面の「最高 KPM」が簡単に水増しできた。30秒未満の走りにはランクを付けず、実績と最高 KPM の対象からも外した。

## 対象ファイル

- `index.html` … `showResult`（ランクの判定と表示）、実績の定義 `ACH`、`renderStats`（最高 KPM）、`resultText` と `shareCard`（共有する文と画像）

## 変更内容

| 対象 | 変更前 | 変更後 |
|---|---|---|
| 結果画面のランク | 練習モードでも常にランクを表示 | 練習モードで30秒未満なら「練習」と表示し、「30秒以上続けるとランクが付きます」と案内 |
| 実績「疾風の指」「神速の指」 | KPM だけで判定 | 30秒以上の走りに限る。説明文も「30秒以上の走りで KPM 300 以上」などに変更 |
| 実績「達人」「閃」 | 練習モード以外 | 練習モード以外で、かつ30秒以上 |
| 記録画面の最高 KPM | すべての走りから | 30秒以上の走りから |
| 共有する文・結果カード | ランクを記載 | ランクのない走りは「練習」「PRACTICE」と記載 |

- スプリント60・デイリー挑戦・弱点特訓は60秒固定なので影響はない。食べ放題は30秒未満で終わった場合だけ対象外になる
- すでに端末に保存されている実績は消さない（新しく付く条件だけを変えた）
