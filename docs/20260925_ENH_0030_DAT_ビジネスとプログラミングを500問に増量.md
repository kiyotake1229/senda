# ビジネスとプログラミングのデッキを500問に増量（閃打）

- 管理番号: #0030
- 種類: ENH（機能改善）
- 対象: お題データ（DAT）
- 作成日: 2026-09-25
- 関連: #0029（4デッキを500問に増量）

## 概要

#0029 で4つのデッキを500問にしたあと、いちばん早く一巡するデッキはプログラミング（333問）とビジネス（337問）になった。この2つも500問に増やした。お題の合計は 4,780 から 5,110 に、ミックスは 4,010 から 4,340 問になった。

## 対象ファイル

- `index.html` … `window.DECKS` の2デッキに330問を追加。リンクの説明文（`og:description`）の語数
- `ogp.png`・`tools/ogp.html` … プレビュー画像の語数を「5,110 語」に
- `README.md` … 語数とテストの件数

## 変更内容

### 問題数

| デッキ | 変更前 | 変更後 | 一巡までの回数（1分に200打の場合） |
|---|---|---|---|
| プログラミング | 333 | 500 | 約18回 → 約27回 |
| ビジネス | 337 | 500 | 約22回 → 約32回 |
| ミックス | 4,010 | 4,340 | 約243回 → 約263回 |
| 合計 | 4,780 | 5,110 | |

### 足した語の内訳

| デッキ | 区分（足した数） |
|---|---|
| プログラミング | 書き方・言語の基本 38、道具と環境 20、テストと不具合 17、ウェブ 25、インフラと通信 14、データとAI 17、セキュリティ 17、開発の進め方 19 |
| ビジネス | メールと敬語 38、会社と働き方 50、会議と企画 26、お金と契約 25、営業と接客 24 |

- 選び方は #0029 と同じ（区分ごとに「よく知られている順」に候補を並べ、区分の枠の中で上から選ぶ）
- 例: プログラミングは「条件式・構文エラー・環境構築・二段階認証・無限スクロール・本番リリース」など、ビジネスは「ご連絡ありがとうございます・日報・稟議書・忘年会・相見積もり・月末締め翌月末払い」など
- 細かすぎる専門用語（符号なし整数・倍精度・仮引数 など）は、候補に入れたうえで優先度を下げ、今回は入れていない
- 他のデッキにある語（満場一致＝ことわざ・四字熟語）は足していない
