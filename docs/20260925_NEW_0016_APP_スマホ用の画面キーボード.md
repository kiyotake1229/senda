# スマホ用の画面キーボード（フリック入力・ローマ字入力）

- 管理番号: #0016
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）、ローマ字入力エンジン（ROM）
- 作成日: 2026-09-25
- 関連: #0013（iOS版の準備）、#0005・#0006（スマホでの操作と案内）

## 概要

スマホで遊べるように、アプリの中に日本語キーボードを作った。Simeji や iOS と同じ12キーのフリック入力で、かなを直接打てる。ローマ字で打ちたい人のために、画面のローマ字キーボードにも切り替えられる。端末のキーボードを使う従来の方法も残した。**パソコン版の見た目と操作は変えていない**（追加はタッチ端末のときだけ出る）。

## 背景

これまではローマ字入力だけだったため、iPhone では端末のキーボードを英語（ABC）に切り替えないと1文字も打てなかった。日本語キーボードは「変換中の文字」としてかなを送るので、そのままでは受け取れない。iOS アプリ化を考えると、この状態では遊べない人が多い。

## 対象ファイル

- `index.html`
  - エンジン（最初の `<script>`）: `createKanaTyper`・`kanaKeyOf`・`kanaCycle`・`kanaTypeable`・`KANA_KEYS` を追加
  - 画面キーボード `MKB`（12キー・フリック・ローマ字パッド・フリック案内）、CSS `.mkb` 一式、`#mkb`
  - ゲーム側: `handleChar` のかな対応、`paintKana`、`nextWord`、`startRun`、`showResult`、`bestKey`、設定「入力方式」、かな用のランク表 `RANKS_KANA`
- `tools/test_kana.js` … 新規。かな入力の自動テスト

## 変更内容

### キーボード（タッチ端末のみ表示）

- **フリック入力**: 12キー（あ〜わ・小゛゜・、）。中央タップで あ段、左＝い段、上＝う段、右＝え段、下＝お段。押している間、指の周りに行き先を表示する（Simeji や iOS と同じ案内）
- 「小゛゜」キーで直前のかなを一巡させる（か→が→か、は→ば→ぱ→は、つ→っ→づ→つ、う→ぅ→ゔ→う など）
- わキーに を・ん・ー、、キーに 。？！ を割り当て
- **ローマ字入力**: 右上の「ABC」で画面のローマ字キーボードに切り替え（英数字・スペース・ハイフン）。左下の「かな」で戻る
- 右下に一時停止ボタン
- 端末のキーボードを使いたい人向けに「外付け」も選べる（従来どおり。Bluetooth キーボードや、英語キーボードに切り替えて使う場合）
- 設定の「入力方式」で、フリック / ローマ字 / 外付け を選ぶ（既定はフリック）

### かな入力の判定

- 出題のかなと、キーボードが送るかなを突き合わせる。同じキーの中の文字なら「途中」として受理する（例: 「が」を出題中に「か」＝受理、続けて濁点で「が」＝確定）
- 途中の文字は、画面のかな表示に橙色で出る
- English デッキはかなで打てないため、自動でローマ字入力に切り替える
- 弱点特訓はローマ字のキー単位で判定する機能のため、フリック入力では選べない

### 記録とランク

- フリックは1打で1かなを出せるため、ローマ字より打鍵数が半分以下になる。そのまま比べられないので、**自己ベストは入力方式ごとに分ける**（キーの例: `sprint:mix|s@kana`）。パソコンの記録のキーは今までどおりで、影響はない
- ランクの基準もフリック用に別表にした（神速 420 / 疾風 340 / 達人 270 / 上級 210 / 中級 160 / 初級 115 / 見習い 70）。実際のプレイの積み重ねで見直す前提の暫定値
- 結果画面・記録画面のお題名に「・フリック」「・画面ローマ字」を付ける

### パソコン版

- タッチ端末でないときは、これまでどおり。キーボードも設定項目も出ない。ローマ字の表示・判定・記録のキーはすべて変更なし

## テスト

```bash
node tools/test_kana.js      # かな入力（3,258件・お題3,212件を実際の操作手順で検査）
node tools/test_romaji.js    # ローマ字（33,187件）
python3 tools/check_decks.py # お題データ
```

- `tools/test_kana.js` は、フリックで出せるかな＋「小゛゜」の押下回数を組み立てて、英語以外のお題 3,212 件すべてを打ち切れることを確認する
- 画面での確認（アプリ内ブラウザのスマホ表示・375px）: フリックで語が進むこと、案内の表示、濁点、一時停止、ABC 切り替え、English デッキの自動切り替え、記録に入力方式が入ること、パソコン表示では何も出ないこと

## 残っている検討

- トグル入力（同じキーを続けて押して あ→い→う と送る打ち方）は未対応。フリックと「小゛゜」だけで全かなを出せる
- 濁点・小文字は1打ぶん増える。実際の指の動きに合わせた数え方で、スコアの比較は入力方式ごとに閉じている
- フリック用のランク基準は暫定。実プレイの記録がたまったら見直す
