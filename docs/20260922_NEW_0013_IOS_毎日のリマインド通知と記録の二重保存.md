# 毎日のリマインド通知と記録の二重保存（閃打）

- 管理番号: #0013
- 種類: NEW（新機能）
- 対象: iOSアプリ（IOS）、アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: なし（iOS アプリ化は未着手。そのための準備）

## 概要

iOS アプリ化（Capacitor）したときに使う機能を、先に `index.html` に組み込んだ。毎日決まった時刻に「今日の1分、打っていきませんか？」と通知するリマインドと、端末の保存領域から記録を戻す仕組み。App Store 審査のガイドライン 4.2（最低限の機能）では、ローカル通知などのネイティブ機能があることが求められる。ブラウザ版では何も変わらない（設定にも出ない）。

## 対象ファイル

- `index.html` … 関数 `isNative`・`canRemind`・`remindPermission`・`remindSchedule`・`remindTest`・`nativeRestore`、設定画面の「毎日のリマインド」カード、起動時の処理、設定 `S.set.remind`（`{on, time}`、既定はオフ・20:00）

## 変更内容

- 通知は Capacitor の LocalNotifications を使う。書き方は「コツコツ」（`habit/`）と同じ
  - 通知 ID 2001: 毎日 `S.set.remind.time` の時刻に繰り返し（`schedule:{on:{hour,minute},repeats:true,allowWhileIdle:true}`）
  - 通知 ID 2002: テスト通知（1.5 秒後に1回）
  - オンにするときに通知の許可を求める。許可されなければオンにしない
  - 起動のたびに予約をかけ直す（時刻を変えたとき・アプリを入れ直したときのずれを防ぐ）
- 記録の二重保存: 保存のたびに `localStorage` と Capacitor の Preferences の両方に書く処理は以前からある。今回、起動時に `localStorage` が空で Preferences に記録があれば、それを戻して再読み込みするようにした（iOS の WebView は `localStorage` が消えることがあるため）
- 触覚フィードバック（Haptics）は以前から対応済み
- iOS アプリ化するときに必要なプラグイン: `@capacitor/local-notifications`・`@capacitor/preferences`・`@capacitor/haptics`
