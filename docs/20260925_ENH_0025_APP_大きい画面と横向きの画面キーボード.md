# 大きい画面と横向きでの画面キーボードの大きさ（閃打）

- 管理番号: #0025
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）、#0018（キーボードの高さと片手モード）

## 概要

画面キーボードが画面の幅いっぱいに広がり、高さも画面の高さの割合だけで決まっていたため、iPad では横に間延びし、横向きのスマホでは窮屈だった。幅と高さに上限・下限を付け、横向きのスマホではお題の文字を小さくして収めた。確認中に、幅の狭いスマホではプレイ中の上の段でスコアが右にはみ出すことも見つけたので直した。

## 対象ファイル

- `index.html` … CSS（`.mkb`・`.mkb-kana`・`.mkb-abc`・横向き用・幅の狭い画面用）、画面キーボードの `applySize`、`TOUCH` の判定

## 変更内容

- キーボードの幅は最大560px。広い画面では中央に置く。片手モードでは左右に寄せる
- 高さは設定の割合（28〜52%）から計算したうえで、170〜440px に収める。お題の表示位置も同じ値で空ける
- 横向きのスマホ（画面の高さ500px以下）でキーボードを出しているときは、お題・よみ・タイマー・コンボの文字を小さくし、ことわざの意味を省く
- 幅430px以下の画面では、プレイ中の上の段のモード名を省く（KPM やスコアが3桁になると、スコアが画面の右にはみ出していた）
- 確認用に、URL に `?touch=1` を付けるとパソコンでもスマホと同じ動き（画面キーボード）になるようにした

確認した内容（アプリ内ブラウザで画面の大きさを変えて確認）:

| 画面 | 結果 |
|---|---|
| 1024×768（iPad 横向き） | キーボードは幅560px・高さ307pxで中央に表示 |
| 844×390（スマホ横向き） | キーボードは高さ170px。上の段・お題・よみ・案内・コンボがキーボードと重ならず、画面が縦にずれない |
| 375×812（スマホ縦向き） | これまでと同じ見た目。KPM・スコアが3桁でも上の段が画面内に収まる |
