# 弱点特訓を選んだままフリックにすると始められない（閃打）

- 管理番号: #0022
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）

## 概要

スマホで、画面ローマ字（または外付け）の設定で「弱点特訓」を選び、そのあと入力方式をフリックに変えると、ホームの「はじめる」を押しても「弱点特訓はローマ字入力のモードです」と出るだけで始まらなかった。弱点特訓はキーボードのキーを狙うモードなので、フリックでは遊べない。ホーム側で選べないようにした。

## 対象ファイル

- `index.html` … `renderHome`（モードの選択の補正）、CSS `.mode.dis`

## 変更内容

- フリックの設定のとき、ホームの「弱点特訓」のカードを薄く表示し、押せないようにした（これまでは薄くする指定だけあって、見た目が変わっていなかった）
- 弱点特訓が選ばれたままフリックの設定でホームを開いたら、自動で「スプリント60」に切り替える
- 念のための「始めない」判定は残した

## 確認URL

| 環境 | URL |
|------|-----|
| ローカル | http://localhost:8791/ （パソコンでスマホの動きを見るときは `?touch=1` を付ける） |

| 本番（GitHub Pages） | https://kiyotake1229.github.io/senda/ |

確認した内容（アプリ内ブラウザのスマホ表示）: 画面ローマ字で弱点特訓を選んでからフリックに変えてホームに戻ると、スプリント60が選ばれ、弱点特訓のカードが薄く押せない状態になり、「はじめる」でプレイが始まること。
