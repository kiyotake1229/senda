# スマホ用キーボードの高さと片手モード（閃打）

- 管理番号: #0018
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）

## 概要

スマホ用の画面キーボード（#0016）が大きいという声を受けて、高さを変えられるようにした。プレイ中はキーボード上端のつまみを上下にドラッグして変えられ、設定画面からも変えられる。あわせて、Simeji にならって、幅を狭めて左右に寄せる「片手モード」を追加した。最初の高さは画面の 46% から 40% に下げた。パソコン版には何も出ない。

## 対象ファイル

- `index.html` … CSS（`.mkb` の高さを変数 `--mkb-h` に、キーの文字の大きさを `--mkb-fs` に、`.mkb-handle`・`.mkb-size`・`.side-left`・`.side-right`）、`MKB` の `applySize`・`applySide`・つまみの操作、設定 `S.set.mkbH`（既定 40）・`S.set.mkbSide`（既定 `both`）、設定画面の2項目、遊び方の文

## 変更内容

- **高さ**: 画面の高さに対する割合で 28%〜52%。キーの文字の大きさはキーの高さに合わせて 15〜24px の間で自動で変わる。キーボードがどれだけ小さくても 170px は確保する
  - プレイ中: キーボード上端の中央にあるつまみを上下にドラッグする。動かしている間は「高さ 34%」のように表示する。キーボードの操作（矢印キー）でも 2% ずつ変えられる
  - 設定画面: 「キーボードの高さ」のスライダー
  - 変えた高さは端末に保存し、次に開いたときも同じ高さになる
- **片手モード**: 設定画面で「左手 / 両手 / 右手」を選ぶ。左手・右手ではキーボードの幅を 84% にして、その側に寄せる
- プレイ画面のお題表示は、キーボードの高さに合わせて下の余白が変わるので、高くしても重ならない
- つまみの操作でゲームが始まったり、キーが押されたりはしない
