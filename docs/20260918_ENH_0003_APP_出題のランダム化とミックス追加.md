# 出題のランダム化とミックス追加（閃打）

- 管理番号: #0003
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）、PWA（`sw.js`）
- 作成日: 2026-09-18
- 関連: #0002（お題の増量。同じ依頼への対応）

## 概要

出題を「山札方式」に変えた。デッキごとにシャッフルした順で出し、一巡するまで同じ語は出ない。続きは次のプレイに持ち越す。全デッキを混ぜた「ミックス」を追加し、初期の選択にした。あわせて、公開版を更新したときに PWA の利用者にもすぐ新しい版が届くよう `sw.js` を直した。

## 対象ファイル

- `index.html` … 出題ロジック（`<script>` の4つ目・5つ目。関数 `bagState` / `bagPeek` / `bagTake`、`startRun` / `nextWord` / `srcTake` / `srcPeek`、`pickHomeWord`）
- `sw.js` … ページ本体をネットワーク優先に変更、キャッシュ名を `senda-v2` に更新

## 変更内容

### 山札方式（変更前 → 変更後）

- 変更前: プレイのたびにデッキをシャッフルし直していた。前のプレイと同じ語が早いうちにまた出ることがあった
- 変更後: デッキごとに「山札」を持つ。シャッフルした順に1枚ずつ出し、全部出し切ったら新しい順でシャッフルし直す
  - 山札の状態は `localStorage` の `senda.v1` の `bags` に保存する。形は `{デッキ: {n: 語数, s: 乱数の種, c: 何巡目, p: 位置}}`。順番そのものは種から毎回作り直すので、保存量は数十バイト
  - デッキの語数が変わったら（お題を足したら）、そのデッキの山札は自動で作り直す
- ホームに表示する語は「山札の次の1枚」。打ち始めるとその語から始まる。Tab で次の1枚に進める（その語は飛ばす）
- プレイ中の「次」の表示も山札の次の1枚
- デイリー挑戦は従来どおり日付で順番が決まる（同じ日なら誰でも同じ出題）
- 弱点特訓は従来どおり、苦手キーを含む語を優先した順（毎回ランダムな重み付き）

### ミックス（新デッキ）

- 「ミックス」＝ 日常のことば・カタカナ語・生きもの・すし屋・地名・ビジネス・ことわざ・プログラミング・短文 を全部まぜた出題（2,952 語）。長文と English は入れていない（打つ速さの性質が違うため）
- お題の並びの先頭に置き、初めて使う人の初期値にした
- デイリー挑戦の出題元も同じ9デッキに広げた

### 表示の整理

- デイリー挑戦のお題名を「ミックス」から「日替わり」に変えた（新しいミックスと区別するため）
- 実績「全席制覇」の条件を「すべてのお題で走った」に変更（ミックスは数えない）
- 設定画面のお題数はミックスを除いて数える（重複して数えないため）
- ひとことに山札とミックスの説明を2つ追加

### sw.js（PWA）

- 変更前: すべてキャッシュ優先。ホーム画面に追加して使っている人は、新しい版を公開しても古いページが出続けることがあった
- 変更後: ページ本体（HTML）はネットワーク優先で最新版を取り、オフラインのときだけキャッシュを使う。アイコン・フォントは従来どおりキャッシュ優先。キャッシュ名を `senda-v1` → `senda-v2` にして古いキャッシュを消す
