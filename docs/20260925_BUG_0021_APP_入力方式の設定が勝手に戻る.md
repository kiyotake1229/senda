# 入力方式の設定が勝手に戻る・プレイ中のかな/ABC切り替えで打てなくなる（閃打）

- 管理番号: #0021
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）、#0024（外付けキーボードへの自動切り替え）

## 概要

スマホの「入力方式」（フリック／画面ローマ字／外付け）の設定が、利用者が変えていないのに書き換わっていた。また、プレイ中に画面キーボードの「ABC」「かな」キーで切り替えると、その走りの残りがすべてミスになっていた。今回の一連の修正（#0020〜#0028）の確認中に見つけた。

## 原因と症状

| 症状 | 原因 |
|---|---|
| 画面ローマ字・外付けを選んでも、アプリを開き直すとフリックに戻る | 画面キーボードは起動時に「かな」の状態で作られる。そのとき「利用者がかなに切り替えた」と同じ知らせを出していたため、保存された設定が毎回フリックで上書きされていた |
| English のお題を1回遊ぶと、以後ずっと画面ローマ字になる | English では画面キーボードを自動で ABC にする。これも「利用者が切り替えた」扱いになり、設定が書き換わっていた |
| プレイ中に ABC／かなキーで切り替えると、打っても全部ミスになる | 設定だけが変わり、いま打っている語の判定（かなで判定するか、ローマ字で判定するか）は元のままだった |

## 対象ファイル

- `index.html` … 画面キーボードの `setMode`（知らせを出す条件）、関数 `setRunIm`・`onPadMode` を追加

## 変更内容

- 画面キーボードは、利用者がキーで切り替えたときだけ設定を書き換える。起動時と English の自動切り替えでは書き換えない
- プレイ中に入力方式が変わったら、いま打っている語を新しい方式で最初から打てるようにする（かな⇔ローマ字の判定を作り直し、ローマ字の表示を出す／隠す）。スコアや経過時間はそのまま
- English のお題の途中で「かな」を押したときは、ABC のままにして「English はローマ字キーボードで打ちます」と知らせる

## 確認URL

| 環境 | URL |
|------|-----|
| ローカル | http://localhost:8791/ （パソコンでスマホの動きを見るときは `?touch=1` を付ける） |
| 開発確認（Artifact） | https://claude.ai/artifact/FuXyid2Rqz9HzPQAVQffZ5 |
| 本番（GitHub Pages） | https://kiyotake1229.github.io/senda/ |

確認した内容（アプリ内ブラウザのスマホ表示）: 画面ローマ字を選んで開き直しても画面ローマ字のままであること。English をフリックの設定で遊んでも設定がフリックのままであること。フリックで始めた走りの途中で ABC に切り替え、画面ローマ字キーボードで文を打ち切れること（正確率100%）、かなに戻すとかなで打てること。外付けに切り替わったあと、次の語に進んでも外付けのままであること。
