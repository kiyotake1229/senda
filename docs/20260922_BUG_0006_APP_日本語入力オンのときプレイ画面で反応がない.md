# 日本語入力オンのときプレイ画面で反応がない（閃打）

- 管理番号: #0006
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: #0008（スマホ向けの案内）

## 概要

日本語入力（IME・日本語キーボード）がオンのままプレイを始めると、キーを押しても何も起きず、理由も表示されなかった。警告はホーム画面の中にしか置いていなかったため。プレイ画面にも警告を出すようにした。特にスマホでは日本語キーボードのままの人が多く、「壊れている」と思われる原因になっていた。

## 対象ファイル

- `index.html` … プレイ画面に警告欄 `#ime-play` を追加、CSS `.imewarn`、JavaScript（関数 `imeWarn`、定数 `IME_MSG`、`keydown` と入力欄 `#hid` の `compositionstart` の処理、`handleChar` で警告を消す処理）

## 変更内容

- 日本語入力の変換が始まったことを検知したら（`keydown` の `isComposing`・`Process`・キーコード 229、または入力欄の `compositionstart`）、今いる画面に合わせて警告を出す。プレイ画面ではお題の下、ホーム画面では従来どおり開始カードの中
- 文言は端末に合わせて変えた
  - パソコン: 日本語入力（IME）がオンのようです。英数に切り替えると打てます（Mac は英数キー、Windows は半角/全角キー）
  - スマホ: 日本語キーボードになっています。英語（ABC）キーボードに切り替えると打てます
- 正しく1文字打てたら、プレイ画面の警告は自動で消える。新しいプレイを始めたときも消える
