# ことわざ・四字熟語の意味表示（閃打）

- 管理番号: #0010
- 種類: NEW（新機能）
- 対象: お題データ（DAT）、アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: #0002（お題の増量）

## 概要

「ことわざ・四字熟語」デッキの 350 語すべてに意味を付け、打つ語の下に表示するようにした。遊びながら言葉の意味も覚えられる。ミックス・デイリー挑戦でことわざが出たときも表示する。設定で表示を消せる。

## 対象ファイル

- `index.html` … お題データ `window.DECKS.kotowaza.items` の各要素に3つ目（意味）を追加。表示欄 `#s-mean`（プレイ画面）・`#hw-mean`（ホームの開始カード）、CSS `.s-mean`・`.w-mean`、設定 `S.set.mean`（既定はオン）、関数 `nextWord`・`pickHomeWord`
- `tools/check_decks.py` … 3つ目の要素（意味）を検査するようにした（8〜48字、英数字・かっこ・句点なし）

## 変更内容

- データの形: `["表示", "よみ", "意味"]`。意味はことわざ・四字熟語のデッキだけに付ける（他のデッキは従来どおり2要素）
- 意味は現在の辞書の一般的な意味。誤用の多い語は正しい意味だけを書いた（例: 情けは人の為ならず＝人に親切にすれば、巡り巡って自分に良い報いがあること。気が置けない＝遠慮や気づかいがいらず、心から打ち解けて付き合えること）
- 作成は3人で分担し、作業者が 350 件を全件読んで確認した
- 設定画面「表示」に「ことわざ・四字熟語の意味を表示」を追加
