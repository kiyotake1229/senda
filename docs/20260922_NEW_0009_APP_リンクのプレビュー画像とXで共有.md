# リンクのプレビュー画像とXで共有（閃打）

- 管理番号: #0009
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: なし

## 概要

公開URLを SNS やチャットに貼ったときに、画像付きのカードで表示されるようにした（OGP の設定と画像 `ogp.png` の追加）。結果画面に「Xでシェア」ボタンを足し、スコア・ランク・KPM・正確率を入れた投稿文をワンタップで作れるようにした。

## 対象ファイル

- `index.html` … `<head>` に OGP（`og:*`）・X 用（`twitter:card`）・`canonical` の指定を追加。結果画面に `#b-x`（Xでシェア）を追加。関数 `xUrl`
- `ogp.png` … 新規。プレビュー画像（1200×630）
- `tools/ogp.html` … 新規。`ogp.png` の元データ。書き出し方はファイル冒頭のコメントにある（Chrome の画面なしモードで撮影）

## 変更内容

- プレビュー画像: ロゴ「閃打」、タグライン「指先が、閃く。」、「1分で腕前がわかる日本語タイピング」、打っている途中の画面の見本（閃光 / senkou）、「3,722語」「ローマ字はどの打ち方でもOK」「登録なし・無料」、URL
- OGP の文言: タイトル「閃打 SENDA｜1分で腕前がわかる日本語タイピング」、説明「3,722語・ローマ字はどの打ち方でもOK。登録なし・無料で、ブラウザですぐ遊べる日本語タイピングゲーム。」
- 画像の URL は公開版の絶対パス（`https://kiyotake1229.github.io/senda/ogp.png`）。Artifact 版にはプレビューは出ない（Artifact は非公開のため）
- 「Xでシェア」: X の投稿画面（`https://twitter.com/intent/tweet`）を新しいタブで開く。投稿文の例:
  `閃打 スプリント60「ミックス」でスコア 412（上級）・KPM 452・正確率 97.8% #閃打` ＋ 公開URL
  - ランクのない練習（#0007）はランクを書かない
  - 送信はX側で本人が行う。アプリからは何も送らない（通信なしの方針は変わらない）
