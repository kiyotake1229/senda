# 実機での動作確認（閃打）

- 管理番号: #0015
- 種類: INQ（調査）
- 対象: 全体（ALL）
- 作成日: 2026-09-22
- 関連: #0014（この確認中に見つかった不具合の修正）、#0009（プレビュー画像）

## 概要

実際の Chrome（Claude in Chrome、macOS）で、公開版（GitHub Pages）と Artifact 版を確認した。公開版は実際のキー入力で一通り動くことを確かめた。その過程で「打ち始めの速い入力がミスになる」不具合を見つけて直した（#0014）。iPhone の実機では確認していない。

## 対象ファイル

- `index.html`（公開版・Artifact 版の両方）

## 確認した内容と結果

### 公開版（https://kiyotake1229.github.io/senda/ 、Chrome 153・macOS）

| 確認 | 結果 |
|---|---|
| ホームの語（扶養控除 fuyoukoujo）を実際のキーで打ってプレイ開始 | 正確率 100%・コンボ 10 で次の語へ（修正後） |
| 表示と違う打ち方（引き継ぎ を hikitugi） | 受理された |
| ミスした打鍵 | 赤い表示・画面の揺れ・食べ放題の −1秒 が出た |
| 一時停止ボタン（実際のクリック） | 一時停止画面が開き、「やめてホームへ」でホームに戻れた |
| 日本語入力 | この環境ではオフ。キーは通常どおり届いた |

- 音は出していない（確認のたびにページの音声機能を止めてから操作した）
- この Chrome には利用者が 2026-09-15 に遊んだ記録（食べ放題・ビジネス ¥9,100 など）が残っていた。確認前に同じ端末内へ退避し、確認後に元へ戻した（退避した内容と完全に一致することを確認）

### Artifact 版（https://claude.ai/artifact/FuXyid2Rqz9HzPQAVQffZ5）

- 1回目に開いたときは正しく表示された（遊び方の画面、フォントの読み込み）
- 打鍵の確認はしていない。Artifact 版は中のページに手を入れられず、音声機能を止められないため
- 2回目以降は白いままだった。調べると Chrome のウィンドウが裏に隠れていて、ページが「非表示」（`document.visibilityState` が `hidden`）の状態だった。Artifact の表示画面は、中のページの準備ができるまで枠を透明（`opacity: 0`）にしておく作りのため、隠れている間は表示が進まない。閃打の不具合ではない。パソコンの前で開けば表示される
- 中身は公開版と同じファイルで、公開版では上のとおり動作を確認済み

### その他

- プレビュー画像: `ogp.png` が公開URLから取得できること（HTTP 200、image/png）と、ページに OGP の指定が入っていることを確認。SNS 上のカード表示は、実際に URL を投稿して確認する必要がある（未確認）
- 自動テスト: GitHub Actions で合格（https://github.com/kiyotake1229/senda/actions ）

### 未確認のもの

- iPhone・iPad の実機（ソフトキーボードでの入力、一時停止ボタン、日本語キーボードの警告）。スマホ幅の表示はアプリ内ブラウザのスマホ表示（375px・タッチ端末扱い）で確認済み（#0005・#0006・#0008）
- Artifact 版での打鍵
