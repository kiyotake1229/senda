# スマホで一時停止と終了ができない（閃打）

- 管理番号: #0005
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-22
- 関連: #0008（スマホ向けの案内）

## 概要

プレイ中に一時停止・終了する方法が Esc キーしかなく、画面にボタンがなかった。キーボードのないスマホでは、スプリント60は60秒待つしかなく、時間制限のない練習モードはページを開き直すまで終われなかった。プレイ画面の左上に一時停止ボタンを追加して直した。

## 対象ファイル

- `index.html` … プレイ画面の HTML（`.p-left` に `#b-pause` を追加）、CSS（`.p-top` の重なり順、ボタンの大きさ）、JavaScript（`#b-pause` のクリック処理、`#b-resume`、`show()` のフォーカス処理、`startRun` の案内文）

## 変更内容

- プレイ画面の左上に一時停止ボタン（一時停止アイコン）を置いた。押すと一時停止画面が開き、「再開する」「最初からやり直す」「やめてホームへ」が選べる。練習モードでは「終了して結果を見る」も出る
- スマホでキーボードが閉じたときに出る「画面をタップして再開」の覆いより手前にボタンを置き、覆いがあっても押せるようにした
- 「再開する」を押したとき、押した瞬間に入力欄へフォーカスを戻すようにした。iPhone はボタンを押した操作の中でないとキーボードを出さないため
- 画面の切り替え時のフォーカスも、待ち時間（50ms）を入れずにその場で行うようにした（同じ理由）
- スマホでは画面下の案内を「Esc 一時停止 / やめる」から「左上のボタンで一時停止・終了」に変えた。練習モードの開始前の案内も「左上のボタンで終了して結果を見る」にした
