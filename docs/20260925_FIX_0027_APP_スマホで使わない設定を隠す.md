# スマホで使わない設定を隠す（閃打）

- 管理番号: #0027
- 種類: FIX（軽微な修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0016（スマホ用の画面キーボード）

## 概要

設定画面の「画面キーボードを表示」「運指の色分け」「特訓のヒント減衰」は、パソコンのキーボードの図に関する設定で、スマホでは表示されない図のためのものだった。スマホでは設定画面に出さないようにした。

## 対象ファイル

- `index.html` … `renderSet`

## 変更内容

- スマホ・タブレット（画面を指で操作する端末）では、上の3項目を表示しない。値はそのまま残る
- パソコンの設定画面は変わらない

## 確認URL

| 環境 | URL |
|------|-----|
| ローカル | http://localhost:8791/ （パソコンでスマホの動きを見るときは `?touch=1` を付ける） |
| 開発確認（Artifact） | https://claude.ai/artifact/FuXyid2Rqz9HzPQAVQffZ5 |
| 本番（GitHub Pages） | https://kiyotake1229.github.io/senda/ |

確認した内容（アプリ内ブラウザ）: スマホ表示の設定画面に3項目が出ず、「入力方式」「キーボードの高さ」「片手モード」は出ること。
