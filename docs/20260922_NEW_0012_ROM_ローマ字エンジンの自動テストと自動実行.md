## 概要

ローマ字入力エンジンの自動テスト `tools/test_romaji.js` を作った。以前のテストは一時フォルダと一緒に消えていて、アプリ内の自己テスト（87 件）しか残っていなかった。あわせて、GitHub に push するたびにテストとお題の検査が自動で走るようにした（GitHub Actions）。

## 対象ファイル

- `tools/test_romaji.js` … 新規。`index.html` の最初の `<script>`（エンジン）を読み込んで検査する
- `.github/workflows/test.yml` … 新規。main への push と pull request で `node tools/test_romaji.js` と `python3 tools/check_decks.py` を実行

## 変更内容

テストの中身（合計 33,187 件）:

1. 受理・拒否の表: し＝si/shi/ci、ち＝ti/chi、じゃ＝ja/jya/zya、てぃ＝thi/texi、ん＝n/nn/xn の使い分け（かんい は kani 不可 など）、っ＝子音重ね/xtu/ltsu（っな は nna 不可）、記号
2. 最初に表示するローマ字（し→shi、かんい→kanni、っっ→xtuxtu など）
3. 打ち方に合わせた表示の切り替え（し に c → ci、ちゃ に t → tya など）
4. ミスした打鍵で状態（表示・進み具合）が変わらないこと
5. 総当たり: ひらがな1〜2文字の全組み合わせ（7,656 語）で、表示どおりに打てば最後まで打ち切れること、進み具合が単調に増えて最後にかなの数と一致すること、どの打ち方も短い打ち方に隠れず到達できること
6. お題データ 3,722 件の全件が表示どおりに打ち切れること

テストの効き目の確認: エンジンにわざと不具合を2つ入れた一時コピー（し の ci を消す、っ の子音重ねに n を許す）で実行し、4 件の失敗として検出されることを確かめた。

```bash
node tools/test_romaji.js        # 失敗があれば終了コード 1
```
