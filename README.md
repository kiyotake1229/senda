「指先が、閃く。」1分で腕前がわかる日本語タイピングゲーム。デスクトップの物理キーボードが主戦場で、iPhone / iPad でも動く。

## 何ができるか

- **ホーム画面がそのまま打てる。** 表示された語を打ち始めた瞬間に60秒が始まる。Enter / Space でも開始
- **出題は山札方式。** デッキをシャッフルした順に出し、一巡するまで同じ語は出ない。続きは次のプレイに持ち越す
- **語の長さを選べる。** ぜんぶ／みじかめ（よみ6字以下）／ながめ。English では単語と英文に分かれる
- **ことわざ・四字熟語は意味も出る。** 350語すべてに意味付き（設定で消せる）
- **お題は11デッキ＋ミックス（合計5,110問）。** 日常のことば・カタカナ語・生きもの・季節・すし屋のことば・日本の地名・ビジネス・ことわざ・四字熟語・プログラミング・短文・長文・English。ミックスは長文と English 以外を全部まぜた出題（初期の選択）
- **ローマ字は全表記対応。** し = si / shi / ci、ん = n / nn / xn、っ = 子音重ね / xtu、じゃ = ja / jya / zya など。打ち方に合わせて表示が切り替わる（`index.html?test=1` で自己テストが見られる）
- **5モード**
  - スプリント60 … 60秒で腕前を測る基本モード。ランク判定・自己ベスト・ゴースト対象
  - デイリー挑戦 … 日付で出題が決まる。1日1回だけ「本番」として記録、連続日数がつく
  - 食べ放題 … ノーミスで語を打ち切ると時間が延び、ミスで1秒減る。金額を稼ぐ（寿司打式）
  - 弱点特訓 … ミスが多いキー・反応が遅いキーを狙って出題。ヒントは3連続正打で消える
  - 練習 … 時間無制限。Esc で終了して結果を見る
- **ゴーストレース。** 自己ベストの走り（1秒ごとの正打数）をレールに表示し、差を打数で示す
- **手応え。** 打鍵音はコンボで音階が上がる（WebAudio 合成・音源ファイルなし）。コンボ25でハイハット、節目で衝撃波、ミスで画面が揺れる
- **結果。** ランクの漢字（入門〜神速）が筆致で現れ、SS 以上は朱印。「次のランクまであと N」「ミス0なら +N」を常に表示。結果カード（1200×630 PNG）の共有・保存と「Xでシェア」ができる。練習モードは30秒以上でランクが付く
- **スマホは画面キーボードで遊べる。** Simeji や iOS と同じ12キーのフリック入力でかなを直接打つ。右上の ABC で画面のローマ字キーボード（句読点・記号キーつき）に切り替え。端末のキーボード（外付け）も選べる（[#0016](docs/20260925_NEW_0016_APP_スマホ用の画面キーボード.md)、[#0020](docs/20260925_BUG_0020_APP_画面ローマ字キーボードで記号が打てない.md)）。キーボードの高さはつまみや設定で変えられ、片手モードもある（[#0018](docs/20260925_ENH_0018_APP_スマホ用キーボードの高さと片手モード.md)）。iPad などでは横に広がりすぎないよう幅を抑え、横向きでも収まる（[#0025](docs/20260925_ENH_0025_APP_大きい画面と横向きの画面キーボード.md)）
- **外付けキーボードは自動で使える。** iPad などでキーボードをつないで打つと、入力方式が自動で「外付け」に切り替わる（[#0024](docs/20260925_ENH_0024_APP_外付けキーボードへの自動切り替え.md)）
- **記録は入力方式ごとに分かれる。** フリックは打鍵数が少ないため、自己ベスト・ランク・実績の基準を分けている。フリックの記録画面ではキーボードの図の代わりに「苦手なかな」を出す（[#0026](docs/20260925_ENH_0026_APP_記録と実績のフリック対応.md)）。パソコンの記録はこれまでどおり
- **スマホでも操作しやすい。** 左上の一時停止ボタン、スマホ向けの案内
- **消音ボタン。** ホーム右上のボタンで音をすぐ消せる。音量の設定は残る（[#0028](docs/20260925_NEW_0028_APP_消音ボタン.md)）
- **公開URLを貼るとプレビュー画像が出る**（`ogp.png`）
- **記録。** スコア推移グラフ、キーボードのミス率ヒートマップ、弱点キー、自己ベスト、デイリーの暦、実績16個
- **設定。** 効果音量、アクセント色5種、ローマ字の表示流儀（shi / si）、文字サイズ、運指の色分け、データの書き出し／読み込み

### スコアとランク

```
スコア = KPM × 正確率³ × (1 + min(最大コンボ, 300) ÷ 1500)
```

| ランク | 漢字 | スコア |
|---|---|---|
| SSS | 神速 | 800〜 |
| SS | 疾風 | 650〜 |
| S | 達人 | 500〜 |
| A | 上級 | 380〜 |
| B | 中級 | 280〜 |
| C | 初級 | 190〜 |
| D | 見習い | 100〜 |
| E | 入門 | 0〜 |

正確率が3乗で効くので、速くても雑だと伸びない設計。

フリックは1文字あたりの操作が少ないため、別の基準を使う（SSS 420〜・SS 340〜・S 270〜・A 210〜・B 160〜・C 115〜・D 70〜。暫定値）。

## お題の追加

`index.html` 内の `window.DECKS` に `["表示", "よみ"]` を足す。よみはひらがな（カタカナ語の長音は ー、句読点は 、。！？ のみ）。English デッキは表示とよみを同じ文字列にする。

足したら必ず検査する。読みの誤りは「そのお題が誰にも打てない」不具合になる。

```bash
python3 tools/check_decks.py        # 形式・送り仮名の整合・重複・最後まで打てるか
python3 tools/check_decks.py --mac  # さらに macOS の読みと突き合わせ（新しく増えた差分だけ目で確認する）
```

デッキの語数が変わると、そのデッキの山札は利用者の端末で自動的に作り直される。

## 修正したいとき

`index.html` を直したら、まずテストを通す。

```bash
node tools/test_romaji.js
node tools/test_kana.js
python3 tools/check_decks.py
```

commit → push すると GitHub Pages に反映される（数分）。push のたびに同じテストが GitHub Actions でも自動で走る（結果: https://github.com/kiyotake1229/senda/actions ）。

```bash
git add -A && git commit -m "変更内容" && git push
```
